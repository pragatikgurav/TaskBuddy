# 📖 About

TaskBuddy is a modern task management application built with **React.js**.

It allows users to easily manage their daily tasks while keeping everything stored locally in the browser.

## Features

- ✅ Add Tasks
- ✏️ Edit Tasks
- ✔️ Mark as Completed
- 🔄 Undo Completed Tasks
- 🗑 Delete Tasks
- 🎯 Priority Levels
- 📂 Categories
- 📊 Progress Tracking
- 💾 LocalStorage Support
- 📱 Fully Responsive UI

# 🚀 Installation

Clone Repository

```bash
git clone https://github.com/pragat026/TaskBuddy.git
```

Move into Project

```bash
cd TaskBuddy
```

Install Dependencies

```bash
npm install
```

Run Project

```bash
npm run dev
```
