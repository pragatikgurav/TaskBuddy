# 📖 About The Project

TaskBuddy is a lightweight and user-friendly task management application designed to improve productivity and simplify daily planning.

Users can create, organize, prioritize, and manage tasks effortlessly while tracking their overall progress. With LocalStorage integration, tasks remain available even after refreshing the browser.

# 🚀 Installation

```bash
# Clone Repository

git clone https://github.com/pragatikgurav/TaskBuddy.git

# Navigate

cd TaskBuddy

# Install Dependencies

npm install

# Run Development Server

npm start
```
